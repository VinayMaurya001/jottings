1. What is a tuple?
    A tuple is an ordered collection of elements, similar to a list, but it is immutable.
    Immutable means you cannot change, add, or remove individual elements after the tuple is created.
    Think of a tuple as a collection whose structure cannot be modified after creation.

    # List: mutable
    numbers_list = [10, 20, 30]
    numbers_list[0] = 99
    print(numbers_list)  # [99, 20, 30]

    # Tuple: immutable
    numbers_tuple = (10, 20, 30)
    # numbers_tuple[0] = 99  # TypeError: tuple does not support item assignment

    print(numbers_tuple)  # (10, 20, 30)



2. Creating tuples
    a = (10, 20, 30)
    print(a)       # (10, 20, 30)
    print(type(a)) # <class 'tuple'>

    # Tuple without parentheses
    b = 10, 20, 30
    print(b)       # (10, 20, 30)

    # Empty tuple
    c = ()
    print(type(c)) # <class 'tuple'>

    # Tuple with one element
    d = (10,)
    print(d)       # (10,)
    print(type(d)) # <class 'tuple'>

    Important: For a single-element tuple, the comma is essential.
    x = (10)
    print(type(x))  # <class 'int'>

    y = (10,)
    print(type(y))  # <class 'tuple'>
    (10) is just an integer inside parentheses. (10,) is a tuple.

    values = (10, 20, 30)
    values = values + (40,)
    print(values)  # # (10, 20, 30, 40)
    The important distinction is that tuples are immutable, but variables can be reassigned.

3. Accessing tuple elements
    Tuples support indexing and slicing, just like lists.
    colors = ("red", "green", "blue", "yellow")
    print(colors[0])     # red
    print(colors[-1])    # yellow
    print(colors[1:3])   # ('green', 'blue')
    print(len(colors))   # 4
    print("green" in colors)  # True


4. Why use tuples instead of lists?
    Use a tuple when the collection represents a fixed group of values that should not be structurally modified.
        coordinates = (25.3176, 82.9739)
        database_config = ("localhost", 5432, "mydb")
        print(coordinates[0])     # 25.3176
        print(database_config[1]) # 5432

    Typical use cases include coordinates, fixed configuration values, and returning multiple results from a function.
    A Java comparison: 
        a Python tuple is not exactly equivalent to a Java collection. 
        Java records are often a better conceptual comparison 
            for fixed groups of named values, while Java lists are mutable collections.

    One important distinction: 
        a tuple cannot have its elements reassigned, 
        but it can contain a mutable object such as a list. 
        That list can still be modified.

        data = ([10, 20], 30)
        data[0].append(99)
        print(data)  # ([10, 20, 99], 30)

        The tuple's first element still refers to the same list; 
            we modified the list itself rather than replacing the tuple element.
        
        values = (10, 20, 30)

6. Tuple unpacking assigns each element to a corresponding variable in order.
        person = ("Amit", 30, "Developer")
        name, age, role = person
        print(name)  # Amit
        print(age)   # 30
        print(role)  # Developer
