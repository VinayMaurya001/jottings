Python is dynamically typed
  value = 10
  print(value)
  value = "Hello"
  print(value)
  value = 3.14
  print(value)
  The same name can refer to objects of different types during execution.
  In Python, the type belongs to the object, not permanently to the variable name.
  Python has a type system, but it uses dynamic typing. 
    The type is associated with the object, 
      and a variable name can refer to objects of different types over time.

type()
  to inspect an object's type.
  age = 30
  print(type(age))  #<class 'int'>
  name = "Vinay"

Swapping variables
  Python handles the assignment elegantly.
    a = 10
    b = 20
    a, b = b, a
    print(a)  #20
    print(b)  #10


important
  x = 10
  Don't think too literally: x = box containing 10
  A better mental model is:
              ┌─────────┐
       x ───► │ int 10  │
              └─────────┘
  Then x = "Hello", now
              ┌─────────────┐
       x ───► │ str "Hello" │
              └─────────────┘
  The name x can refer to different objects.
    This object/reference model will become extremely important when we reach:
    - lists
    - dictionaries
    - functions
    - classes
    - NumPy arrays
    - PyTorch tensors
    The same Python name can refer to completely different objects.
