Lambda, map(), and filter()

Lambda functions
    A lambda is a small anonymous function — a function without a conventional def declaration.

    Syntax:
        lambda arguments: expression
        A lambda can contain only one expression, whose result is returned automatically.


    square = lambda n: n ** 2
    print(square(5))  # 25

    Equivalent regular function:
        def square(n):
            return n ** 2
        print(square(5))  # 25


    add = lambda a, b: a + b
    is_even = lambda n: n % 2 == 0
    print(add(10, 20))       # 30
    print(is_even(4))        # True
    print(is_even(5))        # False

    Best practice: 
        Use def for complex logic or reusable functions with meaningful names. 
        Use lambda for short expressions, 
        especially when passing a function to another function.

    Java comparison: n -> n * n
        Python lambda is similar to a Java lambda expression, 
        though Java's lambda expressions work with functional interfaces.



map() — transform every item

    numbers = [1, 2, 3, 4]
    squares = list(map(lambda n: n ** 2, numbers))
    print(squares)  # [1, 4, 9, 16]
    How it works:
        1. lambda n: n ** 2 defines the transformation.
        2. map() applies it to every item in numbers.
        3. list() converts the resulting iterator into a list.
    
    Important: Python 3's map() returns an iterator, not a list. 
        It produces values as you iterate over it.

    Using a list comprehension:
        numbers = [1, 2, 3, 4]
        squares = [n ** 2 for n in numbers]
        print(squares)  # [1, 4, 9, 16]

    Java equivalent:
        numbers.stream()
           .map(n -> n * n)
            .toList();




filter() — keep items that satisfy a condition
    numbers = [1, 2, 3, 4, 5, 6]
    evens = list(filter(lambda n: n % 2 == 0, numbers))
    print(evens)  # [2, 4, 6]

    How it works:
        - lambda n: n % 2 == 0 returns True for even numbers.
        - filter() retains items for which the function returns True.
        - list() collects those items into a list.
    
    Java equivalent:
        numbers.stream()
            .filter(n -> n % 2 == 0)
            .toList();


Iterator consumption
        numbers = [1, 2, 3]
        result = filter(lambda n: n > 1, numbers)
        print(next(result))  # 2
        print(list(result))  # [3]
        Why?
            filter() creates an iterator that yields values greater than 1: 2, then 3.
            next(result) consumes the first matching value, 2.
            list(result) collects only the remaining value, [3].
            
        The key concept is that an iterator remembers its current position.
            Once a value is consumed, it isn't returned again by that iterator.


        map() returns an iterator
            numbers = [1, 2, 3]
            result = map(lambda n: n * 2, numbers)
            print(list(result))  # [2, 4, 6]
            print(list(result))  # []
            Why? map() returns an iterator, 
                which produces values as you consume it. 
                The first list(result) consumes all three values. 
                The iterator is exhausted, so the second call returns an empty list.

            If you need to use the results multiple times, store them in a list:
                result = list(map(lambda n: n * 2, numbers))
                print(result)  # [2, 4, 6]
                print(result)  # [2, 4, 6]

            numbers = [1, 2, 3, 4]
            result = map(lambda n: n * 10, numbers)
            print(next(result))  # 10
            print(list(result))  # [20, 30, 40]


            numbers = [1, 2, 3]
            result = list(map(lambda n: n + 1, numbers))
            print(result)  # [2, 3, 4]
            print(result)  # [2, 3, 4]

        map() transforms values, filter() selects values, and both return iterators in Python 3.

        
Combining filter() and map()
    You can filter first and then transform the remaining items.

    numbers = [1, 2, 3, 4, 5, 6]
    result = list(
        map(
            lambda n: n ** 2,
            filter(lambda n: n % 2 == 0, numbers)
        )
    )
    print(result)  # [4, 16, 36]


    A list comprehension expresses the same logic more simply:
        numbers = [1, 2, 3, 4, 5, 6]
        result = [n ** 2 for n in numbers if n % 2 == 0]
        print(result)  # [4, 16, 36]

    In Python, list comprehensions are often the clearest choice for simple transformations and filtering.


Quick comparison
    Python	            Purpose	                             Java Streams
    lambda n: n * 2	    Define a small function	             n -> n * 2
    map(func, items)	Transform each item	                 .map(func)
    filter(func, items)	Keep matching items             	 .filter(func)
    list(...)	        Materialize an iterator into a list	 .toList()
