                start: inclusive; defaults to 0 when omitted.
                stop: exclusive.

            for i in range(2, 9, 2):

        total = 0
        for i in range(1, 5):
            total += i
        print(total)
        Here total += i is shorthand for total = total + i. 
        This is called an accumulator pattern, 
            commonly used to calculate sums, totals, and counts in data processing.

Looping through a list
    Python frequently iterates directly over collections instead of using index-based loops.
    
    languages = ["Java", "Python", "SQL"]
    for language in languages:
        print(language)

Using enumerate() to get the index
    Sometimes you need both the item's position and its value.

    languages = ["Java", "Python", "SQL"]
    for index, language in enumerate(languages):
        print(index, language)
    Output:
        0 Java
        1 Python
        2 SQL

    By default, enumerate() starts indexing at 0. You can start at 1 instead:
    for index, language in enumerate(languages, start=1):
        print(index, language)
    Output:
        1 Java
        2 Python
        3 SQL


Nested loops
    A nested loop is a loop inside another loop.

    for i in range(1, 4):
        for j in range(1, 3):
            print(i, j)
    1 1
    1 2
    2 1
    2 2
    3 1
    3 2

    The inner loop completes all its iterations for each iteration of the outer loop.

    Nested loops are useful for working with matrices, combinations, and certain data-processing tasks.
        Be careful with large datasets because nested loops can become expensive.
