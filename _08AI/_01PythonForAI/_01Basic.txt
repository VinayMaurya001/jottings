
Python doesn't require semicolons
  Python uses indentation as part of its syntax, which will become very important.
  Java → ;
    Python → newline
  age = 30
  if age >= 18:
    print("Adult")
  Indentation is mandatory because it defines code blocks.
  Semicolons (;) are optional at the end of a statement.
  In Python, the colon : starts a block, and 
    indentation determines which statements belong to that block. 
    Semicolons are generally unnecessary.
    Concept             Java            Python
    Conditional syntax	if (age >= 18)	if age >= 18:
    Block start	        {	              :

Python comments
  # This is a comment
  Docstrings — documentation for functions and classes
      Python uses triple quotes ("""...""" or '''...''') for docstrings.
        def add(a, b):
            """Return the sum of two numbers."""
            return a + b
        print(add(10, 20))
        You can access the docstring:
            print(add.__doc__)
      Triple-quoted strings are not technically comments. 
        They are string literals, and 
        when placed at the beginning of a function, class, or module, they serve as documentation.
