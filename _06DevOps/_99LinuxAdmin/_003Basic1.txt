File Permissions
  • UNIX is a multi-user system. Every file and directory in your account can be protected
  from or made accessible to other users by changing its access permissions. Every user has
  responsibility for controlling access to their files.
  • Permissions for a file or directory may be restricted to by types
  • There are 3 type of permissions
      • r - read
      • w - write
      • x - execute = running a program
  • Each permission (rwx) can be controlled at three levels:
      • u - user = yourself
      • g - group = can be people in the same project
      • o - other = everyone on the system
  • File or Directory permission can be displayed by running ls –l command
      • -rwxrwxrwx
  • Command to change permission
    chmod   - change mod
      chmod u+w file1  //u for user      
      chmod g-w file1  //g for group
      chmod o-r file1  //o for other
      chmod a-w file1  //a for all

      chmod u+rwx file1  //u for user   
      chmod ugo+r file1


Permission Using Numeric Mode 
  • Permission to a file and directory can also be assigned numerically
    • chmod ugo+r FILE
       OR
    • chmod 444 FILE
        -r--r--r--


  | Permission | Calculation | Numeric |
  | ---------- | ----------- | ------- |
  | `---`      | 0           | 0       |
  | `--x`      | 1           | 1       |
  | `-w-`      | 2           | 2       |
  | `-wx`      | 2+1         | 3       |
  | `r--`      | 4           | 4       |
  | `r-x`      | 4+1         | 5       |
  | `rw-`      | 4+2         | 6       |
  | `rwx`      | 4+2+1       | 7       |


  | Number | Meaning                       |
  | ------ | ----------------------------- |
  | 755    | Executable script/program     |
  | 644    | Normal text file              |
  | 700    | Private directory             |
  | 600    | Private file                  |
  | 777    | Full access (generally avoid) |





File Ownership
  • There are 2 owners of a file or directory
    • User and group
  • Command to change file ownership
    • chown and chgrp
      • chown changes the ownership of a file
          chown root notes.txt
      • chgrp changes the group ownership of a file
          chgrp root notes.txt
  • Recursive ownership change option (Cascade)
    • -R
      chgrp -R developers project

   
    chown user file       # Change owner
    chown user:group file # Change owner and group
    chown :group file     # Change only group
    chgrp group file      # Change group

Access Control list(ACL)
  ACL (Access Control Lists) provide fine-grained permissions beyond the standard Linux permissions (owner, group, others).
  Without ACL:
    User      Group      Others
    rwx        r-x        ---
    You can assign permissions only to:
    One owner
    One group
    Everyone else
  With ACL, 
    you can give permissions to specific users and groups.

  Why ACL?
  Suppose:
      file1
      Owner: root
      Group: developers
      Permissions: rw-r-----
  You want user alice to have read/write access without changing owner or group.
  Normal permissions cannot do this.
  ACL can:
    setfacl -m u:alice:rw file1
  
  Check ACL Support
    mount | grep acl
    Modern RHEL filesystems (XFS, ext4) support ACL by default.

  View ACLs
    ls -l file1
    getfacl file1

  Add/modify ACL 
    For a User
      setfacl -m u:alice:rw file1
    For a Group
      setfacl -m g:developers:rwx file1
    
  Multiple ACL Entries
    setfacl -m u:alice:rwx file1
    setfacl -m u:bob:r-- file1
    setfacl -m g:dev:r-- file1

  Remove ACL
    For user ACL:
      setfacl -x u:alice file1
    For group ACL:
      setfacl -x g:developers file1
    For All ACLs
      setfacl -b file1

  ACL Mask (Very Important)
    The mask limits maximum permissions.
    Change mask 
      setfacl -m m:rwx file1
    Understanding the ACL mask, since exam questions often test why a user doesn't get the permissions you expected.

  Default ACLs (Directory)
    New files inside a directory can automatically inherit ACLs.
    Set default ACL:
      setfacl -d -m u:alice:rwx project
      Every new file inside project inherits that ACL.


  ACL Indicator in ls -l
    -rw-rw----+ 1 root root file1
    Here + means ACL exists.

  Setting w permission with ACL does not allow to remove a file.
    To remove a file permission, we have to give permission using chmod.
