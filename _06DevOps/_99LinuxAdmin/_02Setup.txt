Different ways to install OS  
  1)Via CD/DVD
  2)via ISO image
  3)Via Network Boot
      Basically, you tell your computer to go to a specific IP and a specific folder that is being shared by a shared server.
      That could be either NFS server or a Samba server that attaches that file.
      You give an IP address and then you do the network boot.
