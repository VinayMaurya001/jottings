  Basic Margin & padding Classes
    The margin & padding classes follow this format: m{side}-{size} & p{side}-{size}
    Sides:
      m - margin on all sides
      mt - margin top
      mb - margin bottom
      ms - margin start (left in LTR, right in RTL)
      me - margin end (right in LTR, left in RTL)
      mx - margin left and right (x-axis)
      my - margin top and bottom (y-axis)
    Sizes:
      0 - 0 margin
      1 - 0.25rem (4px)
      2 - 0.5rem (8px)
      3 - 1rem (16px)
      4 - 1.5rem (24px)
      5 - 3rem (48px)
      auto - auto margin (useful for centering)
          No Auto Padding: Unlike margins, padding doesn't have an auto option
  Responsive Margins
    Breakpoint abbreviations:
    sm - ≥576px
    md - ≥768px
    lg - ≥992px
    xl - ≥1200px
    xxl - ≥1400px
  Negative Margins
    Bootstrap 5 also provides negative margin utilities (only available for size 1-5):
    <div class="mt-n5">Negative margin top (-3rem)</div>
    <div class="mx-n3">Negative margins left and right (-1rem)</div>
    No Negative Padding: Negative padding doesn't exist in CSS, so Bootstrap doesn't provide these utilities
  Key Differences from Margins & padding
    No Auto Padding: Unlike margins, padding doesn't have an auto option
    No Negative Padding: Negative padding doesn't exist in CSS, so Bootstrap doesn't provide these utilities


  Aspect Ratio
    Create responsive video or slideshows based on the width of parent.
    Bootstrap 5 includes responsive aspect ratio helpers to maintain consistent proportions for elements 
      like videos, embeds, or custom containers. 
      These utilities are particularly useful for maintaining responsive iframes, images, or other media.
    These aspect ratio utilities help maintain proper proportions across different screen sizes without complex calculations or JavaScript.
    Basic Aspect Ratio Classes
      <div class="ratio ratio-1x1">  <!-- 1:1 Square -->
      <div class="ratio ratio-4x3"> <!-- 4:3 Standard -->
      <div class="ratio ratio-16x9"> <!-- 16:9 Widescreen -->
      <div class="ratio ratio-21x9"> <!-- 21:9 Ultra widescreen -->
    How to Use
      1. For embedded content (like YouTube videos):
        <div class="ratio ratio-16x9">
          <iframe src="https://www.youtube.com/embed/..." title="YouTube video" allowfullscreen></iframe>
        </div>
      2. For custom content:
        <div class="ratio ratio-4x3">
          <div class="d-flex justify-content-center align-items-center">
            <h3>Custom content</h3>
          </div>
        </div>
    Responsive Aspect Ratios
      <div class="ratio ratio-1x1 ratio-md-4x3 ratio-lg-16x9">
        <iframe src="..."></iframe>
      </div>
    Key Features
      No JavaScript required - Pure CSS solution
      Responsive by default - Automatically adjusts with parent container
      Flexible content - Works with iframes, images, or any HTML content
      No extra wrappers - Simple single-div solution
    Custom Aspect Ratios
      You can create custom aspect ratios using CSS variables:
      <div class="ratio" style="--bs-aspect-ratio: 50%;">
        <!-- 2:1 aspect ratio (100%/50%) -->
      </div>
      <div class="ratio" style="--bs-aspect-ratio: 150%;">
        <!-- 2:3 aspect ratio -->
      </div>
    Practical Examples
    1.Responsive video gallery item:
      <div class="col-md-6 col-lg-4 mb-4">
        <div class="ratio ratio-16x9">
          <video controls>
            <source src="video.mp4" type="video/mp4">
          </video>
        </div>
      </div>
    2.Profile image container:
      <div class="ratio ratio-1x1 rounded-circle overflow-hidden">
        <img src="profile.jpg" alt="Profile" class="object-fit-cover">
      </div>
