Grid
  Bootstrap uses a 12-column grid.(Although we canuse less than 12 also but can not use more than 12)
  Layouts are made using .container + .row + .col-* classes.
  Grid classes are responsive and follow breakpoints.

Grid Option Summary
  Feature	        Details
  Grid system	    12-column based
  Gutter spacing	Use .g-0 to .g-5 for horizontal and vertical spacing
  Column width	  Auto by default (.col) or fixed (.col-6, etc.)
  Responsive	    Prefix columns with breakpoints (.col-md-6, .col-lg-4, etc.)
  Alignment	      Use .align-items-*, .justify-content-* for vertical/horizontal alignment
  Offset columns	Use .offset-md-2 to shift columns right
  Order columns	  Use .order-md-1 to change order responsively

.d-grid
  The .d-grid class in Bootstrap 5 enables the CSS Grid layout on an element — 
    it’s a quick utility to turn any container into a grid without writing custom CSS. 
    Super handy for laying out buttons, cards, or form controls in rows and columns.
      <div class="d-grid">
        <button class="btn btn-primary">Button 1</button>
        <button class="btn btn-secondary">Button 2</button>
      </div>
      This stacks the buttons vertically by default (1 column grid).
  Responsive Grid Button Example
    <div class="d-grid d-md-block">
      <button class="btn btn-success">Yes</button>
      <button class="btn btn-danger">No</button>
    </div>
    On small screens: buttons stack vertically.
    On medium+ screens: layout switches to inline-block (horizontal).
