  Input groups
    .input-group 
      this class is a container to inhance an input 
        by adding an icon, text or a button 
        in front or behind the input field as a "Help Text"
      .input-group-sm
      .input-group-lg
    .input-group-text
      <div class="input-group mb-3">
        <span class="input-group-text" id="basic-addon1">@</span>
        <input type="text" class="form-control" placeholder="Username" aria-label="Username" aria-describedby="basic-addon1">
      </div>
      We can Appending Text also
    With Button Add‑on
        <div class="input-group mb-3">
          <button class="btn btn-outline-secondary" type="button" id="button-addon1">Button</button>
          <input type="text" class="form-control" placeholder="" aria-label="Example text with button addon" aria-describedby="button-addon1">
        </div>
    Add multiple inputs or addons
      <div class="input-group mb-3">
        <span class="input-group-text">$</span>
        <span class="input-group-text">0.00</span>
        <input type="text" class="form-control" aria-label="Amount (to the nearest dollar)">
        <span class="input-group-text">.00</span>
      </div>
    With Checkboxes or Radios

         <input class="form-check-input mt-0" type="checkbox" value="" aria-label="Checkbox for following text input">
        </div>
        <input type="text" class="form-control" aria-label="Text input with checkbox">
      </div>
    With Dropdown
      <div class="input-group mb-3">
        <button class="btn btn-outline-secondary dropdown-toggle" type="button" data-bs-toggle="dropdown" aria-expanded="false">Action</button>

          <li><a class="dropdown-item" href="#">Action 1</a></li>
          <li><a class="dropdown-item" href="#">Action 2</a></li>
        </ul>
        <input type="text" class="form-control" aria-label="Text input with dropdown button">
      </div>

    Floating label/Animated Labels
      .form-floating
      Wrap your <input>, <textarea>, or <select> in a .form-floating container.
      Give the control an id and the <label> a matching for.
      Include a non-empty placeholder (won’t be shown once the label floats).
        <div class="form-floating mb-3">
          <input type="email" class="form-control" id="floatingEmail" placeholder="name@example.com">
          <label for="floatingEmail">Email address</label>
        </div>
