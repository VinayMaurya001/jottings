Cards
  In Bootstrap 5, cards are versatile content containers with multiple layout options 
    for images, text, buttons, headers, footers, etc. 
    They're perfect for dashboards, product listings, profiles, and more.
  .card 
  .card-body
  1. Basic Card
    .card-title
    .card-text
      to remove buttom marginsfor a <p> element if it isthe last child inside .card-body
    <div class="card" style="width: 18rem;">
      <div class="card-body">
        <h5 class="card-title">Card title</h5>
        <p class="card-text">This is a simple card with some text.</p>
        <a href="#" class="btn btn-primary">Go somewhere</a>
      </div>
    </div>

  4. Card with Image
    .card-img-top
    .card-img-buttom
    <div class="card" style="width: 18rem;">
      <img src="https://via.placeholder.com/286x180" class="card-img-top" alt="...">
      <div class="card-body">
        <h5 class="card-title">Card with Image</h5>
        <p class="card-text">Image at the top, text and button below.</p>
        <a href="#" class="btn btn-success">Explore</a>
      </div>
    </div>
    .card-img-overlay
      to place text or content on top of an image 
      You can use bg-dark bg-opacity-* or add a semi-transparent background inside the overlay to improve text readability.
Add rounded or shadow for extra polish.
  5. Cards in a Grid (Card Group / Deck)
    .card-group
  6.Link in card
    .card-link on <a> tag
    To style multiple links inside a card consistently. 
    It provides spacing and styling to distinguish links in a card body.
    <div class="card" style="width: 18rem;">
      <div class="card-body">
        <h5 class="card-title">Card with Links</h5>
        <p class="card-text">This card has two related links below.</p>
        <a href="#" class="card-link">Card link</a>
        <a href="#" class="card-link">Another link</a>
      </div>
    </div>
  6.More Card Features
    Cards can contain lists, images, buttons, navs, tables, etc.
    Can be styled with utility classes like shadow, border, rounded, etc.
