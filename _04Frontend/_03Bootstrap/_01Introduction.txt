Bootstrap
	Popular HTML, CSS & JavaScript framework
	Completely free
	Highly Customizable
	Responsive grid system
	Responsive media items
	Build-in components
	Can be extended
	Optional JavaScript plugins
	We dont need to use @MediaQueries

New in Bootstrap 5
	jQuery removed
	Switched to Vanilla JavaScript
	Custom font-sizes
	support all major browser & platform
	Dropped support for IE10, IE11
	Change in Gutter width
	New Icon library
	new components, faster stylesheet & more responsiveness
	Bootstrap 3 & 4is still supported by the team for critical bugfixes & documentation changes 
		& it is practically safe to use them. However new features will not be added to them.

Advantage of Bootstrap
	easy to use
	Responsive
	mobile-first approach
	browser compatibility
