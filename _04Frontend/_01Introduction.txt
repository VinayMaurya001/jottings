1)Sublimetext3 editor
			You can use Sublime Text 3 instead of 2. 
				This will make it to where the HTML5 <!DOCTYPE html>  is included in your HTML boilerplate snippet.
			Also, when you're using the html + tab tab completion shortcut, be sure that the file's syntax is set to HTML. 
			It should say "HTML" in the lower right corner of the window. 
			If it says "Plain Text" then you'll need to click it and change it to "HTML" before the tab completions for HTML tags will work properly.
