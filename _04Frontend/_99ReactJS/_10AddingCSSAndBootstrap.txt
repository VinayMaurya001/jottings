Ways to style React with CSS
  1)Inline style
      let obj={color:"red",backgroundColor:"yellow"}
      style={{obj}};
            or
      style={{color:"red",backgroundColor:"yellow"}}
           or
      style={{...obj1 , ...obj2}};
  2)CSS stylesheet-external style
      .myFont{
        color:red;
      }
      .myFont2{
        background-color:red;
      }
      <h1 className="myFont myFont2">Helloooooooo</h1>
      CSS stylesheet(external style) are globally scoped.
  3)CSS Module
      Stylesheet1.module.css 
          .heading{
            background-color:red;
          }
      import Style from './Stylesheet1.module.css'
      className={Style.heading}
      CSS modules are locally scoped.
      CSS module converted to different format in browser
          Filename_className_hashCode


    In Inline style, we can not use pseudo classes. Eg- :hover, :active, :visited etc.
      But these are available in CSS stylesheet-external style  & CSS module both.
