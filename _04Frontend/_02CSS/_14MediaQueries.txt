Media Queries
Help create a responsive website

@media (width : 600px) {
div {
background-color : red;
}
}

@media (min-width : 600px) {
div {
background-color : red;
}
}


@media (min-width : 200px) and (max-width : 300px) {
 div {
 background-color : red;
 }
 }




Example
    What this does:
    Default → stacked (mobile)
    If screen ≥ 768px → apply flex layout
    main {
      padding: 20px;
    }

    /* Tablet and above */
    @media (min-width: 768px) {
      main {
        display: flex;
        gap: 20px;
      }

      article {
        flex: 3;
      }

      aside {
        flex: 1;
      }
    }
