Display Property
    display: inline / block / inline-block / none
    block - 
        Takes full space available in width.
    inline - 
        Takes only the space required by the element. (no margin/ padding)
    inline-block - 
        Similar to inline 
            Like inline, but you can set width, height, margin, padding
            but we can set margin & padding, width & height from top & buttom.
            but we can set margin & padding, width & height from top & buttom.
    none - 
        To remove element from document flow.
    	Hides the element completely
    flex	
        Makes the element a flex container for flexible layouts
    grid	
        Makes the element a grid container for 2D layouts
    inline-flex	
        Like flex, but behaves like an inline element
    inline-grid	
        Like grid, but behaves like an inline element
    table, table-row, etc.	For table-like layouts

Visibility
    Note : When visibility is set to none, space for the element is reserved.
    But for display set to none, no space is reserved or blocked for the element.
    visibility: hidden/none;

Alpha Channel
    opacity (0 to 1) - 0 means invisible
    RGBA

display: block on <a>
    By default:
        <a> = inline element
        Inline elements:
            Do NOT respect vertical padding properly
            Clickable area only around text
    After:
        display: block;
        Now <a>:
            Behaves like a block box
            Padding applies fully
            Clickable area becomes rectangular
            UX improves significantly
