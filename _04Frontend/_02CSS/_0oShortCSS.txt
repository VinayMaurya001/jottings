Inheritance & Specificity
Inheritance, where if we set a property on a parent it can also affect a child element.
Specificity is this idea in the sense that we can have multiple styles targeting one element.
	So then the SS has to decide which one wins. And in this case whatever style is closest to this element.
	https://specificity.keegan.st/
	https://www.w3.org/TR/selectors-3/#specificity
